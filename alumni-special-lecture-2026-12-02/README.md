## 2. 강의 준비 방향

- **대상 청중:** 전공 지식이나 실무 경험이 충분하지 않은 1학년을 기준으로 설명한다.
- **상위 학년 배려:** 2~4학년에게도 생각할 거리와 배움이 남도록 내용을 구성한다.
- **난이도:** 전문 용어를 사용할 때는 기본 개념과 맥락을 함께 설명한다.
- **준비 순서:** 슬라이드를 먼저 만들기보다 전달하고 싶은 생각과 경험을 수집한 뒤 강의 구조를 정한다.
- **진행 방식:** 떠오르는 이야기와 아이디어를 차례대로 기록하고, 나중에 주제별로 분류해 다듬는다.

### 구성 시 검토할 제안 (아직 확정하지 않음)

- 실무 엔지니어로서의 경험을 학생들이 이해할 수 있는 구체적인 사례로 소개하기
- 1학년에게는 흥미와 진로 탐색의 계기를, 고학년에게는 향후 실무에 적용할 관점을 제공하기
- 실습이나 기술적인 설명을 넣을 경우 필요한 배경지식을 먼저 제공하기
